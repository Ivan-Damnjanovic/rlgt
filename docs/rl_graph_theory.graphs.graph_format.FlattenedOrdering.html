This enumeration encapsulates the concept of an edge (resp. arc) ordering in the context of the two flattened graph formats, GraphFormat.FLATTENED_ROW_MAJOR and GraphFormat.FLATTENED_CLOCKWISE, from the GraphFormat enumeration.

Constant CLOCKWISE This item corresponds to the clockwise edge (resp. arc) ordering.
Constant ROW_MAJOR This item corresponds to the row-major edge (resp. arc) ordering.
