rl_graph_theory.graphs

package documentation

The rl_graph_theory.graphs package contains the two core classes Graph and GraphBatch, which encapsulate the concept of a $k$-edge-colored looped complete graph and a batch of $k$-edge-colored looped complete graphs of the same order, respectively. The package also contains the GraphFormat enumeration, which encapsulates the concept of a format used to represent a $k$-edge-colored looped complete graph, alongside various classes that are used to construct $k$-edge-colored looped complete graphs with some particular structure.
