rlgt.graphs.special_graphs.BookGraph

class documentation

class BookGraph(Graph):

Constructor: BookGraph(graph_formats, index)

View In Hierarchy

This class inherits from the Graph class and is used to instantiate book graphs. Specifically, it produces a 2-edge-colored loopless complete undirected graph such that its edges colored with the color 1 form a book graph, while all other edges are colored with the color 0. A book graph of index m is a simple graph on m + 2 vertices where vertices 0 and 1 are adjacent to each other and to all remaining vertices, and the remaining m vertices are independent, i.e., no edges exist between them. The class also allows selecting the initial graph formats in which an instance should be represented.
