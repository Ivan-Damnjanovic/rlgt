rl_graph_theory.graphs.special_graphs

module documentation

This Python module contains various classes that inherit the Graph class and are used to construct concrete edge-colored complete graphs with a given structure.

Class AlmostCompleteGraph This class inherits the Graph class and it is used to instantiate almost-complete graphs. In other words, it produces a graph of a given order and with two available edge colors such that all of its edges are colored in the color 1, except for the edge between the last two vertices, which is colored in the color 0...
